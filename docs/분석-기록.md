## 자산과 모션

원본 유닛 시트·전투 초상화·작은 초상화·사용 가능한 전신 일러스트를 그대로 사용했습니다. 별도 서버 주소를 게임에 복사하지 않았으며, 실행 시 필요한 파일은 모두 `dist` 안의 상대 경로로 요청합니다.

CGG 한 행은 앵커와 부분 개수 다음으로 각 부분의 11개 값이 이어집니다. 위치, 뒤집기, 합성 방식, 투명도, 회전, 시트 자르기 영역, 페이지 번호입니다. CGS는 CGG 프레임 번호, 위치 보정, 60분의 1초 단위 지속 시간입니다. 캔버스에 부분들을 역순으로 그리며 일반 합성과 가산 합성을 구분합니다.

발가스 이동 모션의 지속 시간 0은 재생 시 최소 한 프레임으로 보정합니다. 만드라고라의 이동 CGS는 APK에 없어 대기 모션을 사용하며 `animations.json`의 `fallbackActions`에 기록했습니다. 별도 필살기 이펙트 시트는 복원하지 않았습니다. 필살기는 공격 모션과 웹판에서 그린 속성 효과를 조합합니다.

## 모바일 화면

`layout_header.csv`, `layout_home2.csv`, `layout_footer2.csv`, `layout_battle.csv`의 좌표와 원본 이미지 아틀라스를 사용했습니다. 추출한 배치 원문은 `ui-layout-source.json`에 보존했습니다. 홈의 다섯 캐릭터 프레임, 중앙 리더, 여섯 하단 메뉴, 금색 테두리와 푸른 패널, 전투의 아군 오른쪽·적 왼쪽 배치를 적용했습니다. `footer_btn.plist`에 정의된 회전된 이미지 영역도 그대로 해석합니다.

원본 BRAVE FRONTIER 로고는 그대로 표시합니다. 그 외 영문이 이미지에 합쳐져 있는 부분은 원본을 변경하지 않고 웹 화면에서 한글 라벨로 가렸습니다. 따라서 그림은 원본이지만 한글 글꼴과 버튼 글자, 화면 높이에 따른 여백까지 픽셀 단위로 동일한 복제는 아닙니다. 미구현인 아레나·레이드·온라인 친구 메뉴는 그 사실을 표시합니다. 마을 시설과 상점은 현재 웹판에서 실행 가능한 편성·성장·소환 기능으로 연결합니다.

## 한국어 자료

`BluuArc/bfmt-data`의 `kr/unit/<유닛번호>.json` 24개를 읽어 `units-source-kr.json`에 보존했습니다. 이름, 속성, 희귀도, 기본·최대 능력치, 타격 수, 필살기 이름·설명·비용, 영웅 리더 효과를 사용합니다. 각 변환 유닛에는 원문 주소와 원문 수정 시각이 들어 있습니다. 이 자료는 2016년 자료이며 글로벌 APK 2.19.6.0과 정확히 같은 데이터라고 간주하지 않습니다.

화면에 표시하는 체력·공격력·방어력·회복력·필살기·결정 등은 한국어로 통일했습니다. APK에 남은 `tuto1`·`tuto9`의 조작 순서와 대사를 한국어로 재구성했습니다. `tuto15`·`tuto16` 원문도 보존했지만, 중간 합성·세 번째 퀘스트 자료가 없어 전체 이야기 흐름에 연결하지 않았습니다. 구간별 원문 줄 번호는 `tutorial.js`에 연결했습니다.

## 웹판 규칙

- 시작 재화: 젤 2,500, 카르마 800, 보석 6. 시작 영웅과 다른 속성의 지원 유닛 두 명을 지급합니다.
- 부대: 서로 다른 보유 유닛 1~5명. 이전 버전의 6명 저장 파일은 손실 없이 읽으며, 다음 편성 저장부터 5명 제한을 적용합니다. 첫 유닛의 적용 가능한 리더 효과를 사용합니다.
- 성장: 모든 유닛을 레벨 1~20으로 통일하고 기본·최대 능력치 사이를 선형 보간합니다. 강화 비용은 젤 `100 + 현재 레벨 × 35`, 카르마 `40 + 현재 레벨 × 18`입니다. 모험 경험치로도 레벨이 오릅니다.
- 피해·상성·치명타·가드·스파크·결정: 원본 네이티브 함수를 읽어 기본 규칙을 수정했습니다. 식과 함수 주소, 적용 범위는 [전투 원본 대조](전투-원본-대조.md)에 있습니다. 전체 패시브·버프·필살기 효과 처리기를 복원한 것은 아닙니다.
- 일반 공격 타격: 한국어 원문 프레임과 타격별 분배에 따라 예약하고 해당 시점에 체력을 차감합니다. 같은 타깃·같은 타격 프레임의 패킷에 스파크 1.5를 적용합니다. 사망 뒤 남은 타격은 연출을 끝내고 실제 피해를 0으로 기록합니다.
- 결정: 살아 있는 동료에게 무작위 배분합니다. 하트는 부상자를 우선합니다. 피격·방어의 고정 게이지 증가를 제거했습니다. 결정 도착 때만 수치를 반영합니다. 드롭 확률과 800ms 비행 시간은 원본 미확인인 웹판 값입니다.
- 회복약: 도전마다 세 번, 생존한 부상 유닛에게 최대 체력의 절반을 회복합니다. 다음 전투로 넘어갈 때 생존한 동료는 최대 체력의 15%를 회복합니다.
- 모험: 일반 6개와 특별 2개를 직접 구성했습니다. 특별 탐험은 두 번째 일반 모험을 마치면 열립니다. 전투 수, 적 배치·배율, 보상, 첫 완료 동료는 웹판 설정입니다.
- 일반 소환: 젤 350으로 시작 영웅 외 20종 중 균등 선택. 중복 시 카르마 200입니다.
- 영웅 소환: `tuto15`에서 확인한 보석 5로 미보유 시작 영웅 중 균등 선택. 네 영웅을 모두 보유하면 네 명 중 선택하며 중복 시 카르마 500입니다. 실제 결제 기능은 없습니다.
- 저장: 브라우저의 로컬 저장소를 사용합니다. 승리 보상은 전투 상태별 한 번만 반영하고, 일반 전투 진행 자체는 저장하지 않습니다. 훈련 두 장의 완료와 현재 전투 시작 지점은 별도로 저장합니다. 훈련은 임시 부대로 진행해 소유 동료·재화를 바꾸지 않습니다. 파일 불러오기는 구조와 유닛·편성·재화 범위를 검증한 뒤 적용합니다.

## 남은 범위

추가로 다운로드되던 자산·원본 임무 자료·서버 규칙이 필요합니다. 전체 지역과 이야기, 진화·합성 시스템, 장비, 아레나·레이드·길드, 친구·계정 기능은 현재 구현하지 않았습니다. 현재 확인 가능한 범위는 두 장의 훈련, APK 수록 캐릭터 24종의 수집·편성·성장, 웹판 여덟 모험입니다. [캐릭터·페이지 검토표](캐릭터-페이지-검토.md)에 화면별 차이와 필요한 원본 파일을 적었습니다.
