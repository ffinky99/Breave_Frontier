# 검증 기록

검증일: 2026년 10월 24일. 정적 웹판 0.1.0과 원본 모바일 UI 적용 상태를 확인했습니다.

## 자동 검증

`npm test`의 16개 검증이 모두 통과했습니다.

- 시작 영웅 4명, 서로 다른 난수 60개씩 총 240회 첫 모험 완주
- 한 차례 중복 행동 방지, 필살기 게이지 부족 시 상태 유지
- 속성 상성, 방어 피해 감소, 전체 공격 필살기
- 회복약 횟수·생존 조건, 전멸과 패배
- 승리 보상 한 번 지급, 다음 모험 해금, 재도전 보석 미지급
- 성장 비용·최대 레벨, 편성 제한
- 영웅 미보유 우선 소환, 일반 소환 20종, 중복 보상
- 저장 파일 복원, 잘못된 재화·레벨·편성·기록 거부
- 최대 성장 부대로 웹판 모험 8개 완주
- 0 길이 프레임 보정, 누락 이동 모션의 기록된 대체 처리

`npm run check`도 통과했습니다. 자바스크립트 구문, 원본 자산 141개 각각의 크기·SHA-256, 유닛 24종의 이미지 존재 여부, 모션 자르기 영역, 회전된 UI 아틀라스 영역, 정적 파일 참조와 한국어 문서 언어를 확인합니다. 실행 소스에서 외부 URL을 참조하지 않는지도 검사합니다.

## 브라우저에서 직접 확인한 흐름

1. 첫 영웅 선택 → 티리스 안내 → 마을 진입.
2. 첫 모험 출발 → 방어 → 일제 공격 → 자동 전투와 두 배속 → 연속 전투 3회 완료.
3. 첫 완료 보상과 중복 동료 보상 반영, 다음 지역 해금.
4. 발가스 강화 시 레벨·능력치 증가와 재화 차감.
5. 영웅 소환으로 에젤 획득, 보석 3개 차감.
6. 네 명으로 편성 → 새로고침 → 레벨·동료·편성·재화 유지.
7. 원본 모바일 UI로 교체한 뒤 전투 메뉴의 방어, 자동 전투, 재도전 완료.
8. 원본 메뉴·프레임·금색 테두리·회전된 하단 메뉴 이미지의 실제 렌더링 확인.
9. 저장 파일 내려받기 후 실제 JSON의 동료·편성·재화·완료 횟수가 화면과 일치하는지 확인.

모바일 UI 적용 후 재도전 보상은 젤 350, 카르마 180이었으며 첫 완료 보석은 다시 지급되지 않았습니다. 내보낸 파일의 동료 4명·편성 4명·완료 2회·젤 3,065·카르마 1,222·보석 6이 화면과 일치했습니다. 이는 검증 브라우저의 테스트 기록으로, 배포 파일에 개인 진행 상황을 넣지 않았습니다.

강화 직후 홈의 레벨 표시가 갱신되지 않는 문제가 발견되어 수정했습니다. 저장 파일의 잘못된 편성 키도 거부하도록 보완했습니다.

## 검증하지 못한 범위

파일 불러오기 버튼에서 브라우저의 파일 업로드 승인이 거절되어 실제 파일 선택부터 완료까지의 검증은 중단했습니다. 우회하지 않았습니다. JSON 형식 검사와 복원 로직은 자동 검증을 통과했습니다.

실제 안드로이드·아이폰 기기에서의 터치 동작과 소리 출력은 별도로 확인하지 않았습니다. 브라우저에서 원본 프레임과 세로 화면 구성을 시각적으로 확인했습니다. 원본 서버의 전투 결과와 수치 비교는 하지 않았으며, 웹판 전투 규칙은 원작과 구분해 문서화했습니다.
