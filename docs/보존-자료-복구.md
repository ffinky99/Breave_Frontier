# 공개 보존 자료 복구 기록

2026-10-25 · Project Brave Archive의 공개 `21900.zip`에 접근해 ZIP64 목록과 필요한 구간을 다운로드했습니다. 원본 ZIP 전체 14,465,448,570바이트를 받을 필요 없이, 압축되지 않은 내부 `assets.zip`의 인덱스와 선택 파일을 HTTP Range로 읽었습니다. 파일별 ZIP CRC32와 SHA-256을 확인했습니다. 원본 서버나 계정 데이터에 접근한 것은 아닙니다.

## 확보한 자료

| 범위 | 확인 결과 |
| --- | --- |
| 보존 스냅샷 | 2022-04-03 글로벌 Windows 클라이언트 자료와 과거 추가 파일. 출처 설명 원문은 `sources/archive-README.txt` |
| 내부 assets 목록 | 파일 76,005개. 압축한 전체 인덱스 `preservation-catalog.json.gz` |
| APK 누락 참조 | 3,393개 중 3,301개에 해당하는 파일 다운로드·무결성 검증. 92개는 이 아카이브에서 미확인 |
| 이번에 실제 검증한 파일 | 중복 경로를 제외한 3,738개. 목록·경로·압축 위치·크기·CRC32·SHA-256은 `preservation-inventory.json` |
| 추가 원문 | 임무·유닛·모션 매핑 등 마스터 9개. 적용한 24유닛과 임무 1·2·10의 부분집합 및 원본 해시는 `preservation-master-subset.json` |
| 튜토리얼 | `tuto1`~`tuto16`, `tuto101`~`tuto103`의 19개 파일. `tuto3`은 내용 없는 파일이며, 파일이 있다는 이유로 장면을 복원했다고 보지 않음 |
| 화면 배치 | CSV 715개. `preservation-layouts.json`에 원문 보존 |
| 캐릭터 아틀라스 | `unit_anime_<ID>.png` 파일 2,183개를 인덱스에서 확인. 이 수치를 구현된 캐릭터 수로 표시하지 않음 |

`matchedMissingReferences`는 원래 APK의 resourceMap에 기록된 **파일 이름**을 기준으로 대조했습니다. 아카이브에 같은 파일 이름이 여러 경로에 있는 경우 원래 경로를 모두 남겼습니다. 같은 이름이라는 사실만으로 APK와 바이트·지역판·버전이 같다고 판단하지 않습니다.

## 실제 게임에 적용한 변경

- 현재 플레이 가능한 24종 중 전신 일러스트가 없던 16종의 원본 PNG를 추가했습니다. 기존 APK의 8종 그림은 유지했습니다. 배포 자산은 APK 211개 + 공개 보존 그림 16개 = 227개입니다.
- 24종 모두 마스터의 홈 화면 crop을 읽습니다. 원본 `HomeScene2::unitDraw`는 원본 이미지의 지정 사각형을 잘라 640 기준 128×350으로 표시합니다. 이를 고정 `object-fit` 대신 캔버스로 구현했습니다. `sources/native-ui-interpretation.json`과 원문 명령어 기록에 근거가 있습니다.
- 24종 × 대기·이동·공격의 72개 시퀀스는 마스터가 지정한 APK CSV와 모두 일치합니다. 만드라고라의 이동은 `unit_idle_cgs_30050.csv`를 명시적으로 재사용하므로 미확인 fallback 표시를 해제했습니다.
- 안내 손의 TOUCH/HOLD는 원본 손 모양·프레임과 라벨 테두리를 유지하며 런타임에서 터치/길게로 표시합니다. 원본 PNG 파일은 수정하지 않았습니다.
- 초원의 구름·바람·햇빛 SAM을 연결했습니다. 각 24fps·1200프레임, 중심 320/220, 좌상단 0/−100, additive 레이어 구분을 적용했습니다. 실행 자산은 기존 APK에서 추출했으며 서버 자료에서 찾았다고 표기하지 않습니다.
- 두 훈련의 여섯 웨이브에 적 ID·HP·ATK·DEF·속성과 일반 공격 AI를 공개된 **2014년 GL 파싱 캡처**에서 적용했습니다. 보스 HP는 모릴스 킹 3000, 스켈레톤 4000입니다. 캡처 원문과 고정 커밋·해시는 `sources/capture-manifest.json`에 있습니다.

`F_MISSION_MST`의 1·2·10번은 전투 수 3·3·5와 선행 임무 1→2→10을 확인할 수 있지만, 적의 웨이브·HP·AI가 들어 있지 않습니다. 따라서 **2014 캡처의 적 수치가 2022년 서버와 동일하다는 결론은 내리지 않았습니다.** 유도 공격 피해·아군 임시 구성·원본 화면 슬롯 좌표·일반 모험·보상은 아직 웹판 구현이 섞여 있습니다.

## 남은 범위

92개 미확인 참조는 `preservation-inventory.json.unresolvedReferences`에 있습니다. 또한 파일을 확보한 것과 그 파일을 원본 규칙에 맞게 실행하는 것은 다릅니다. 2,183개 아틀라스 전체의 한국어 데이터·전투 효과·진화·다중 페이지 모션을 연결한 상태가 아닙니다. 실행 가능한 유닛은 여전히 24종입니다.

연결 튜토리얼, 합성 안내, 칼의 소환 안내·작별, 다른 페이지 배치 파일은 확보했지만 아직 전체 장면 실행기를 포팅하지 않았습니다. GL 임무 3은 최신 보존 마스터에도 없으며, JP의 임무 3을 GL과 동일한 것으로 섞지 않았습니다. 원작 계정·온라인 서버·확률·모든 전투 AI는 별도의 복원 대상입니다.

## 재현

표준 Python만으로 공개 아카이브의 검증된 파일들을 다시 받을 수 있습니다. 정상 파일은 건너뛰므로 중단 후 다시 실행할 수 있습니다. 링크가 바뀌거나 공개 다운로드가 중지되면 실패하며, 인증을 우회하지 않습니다.

```sh
python3 scripts/recover-preservation.py /작업경로/recovered
python3 scripts/extract-apk.py /경로/brave-frontier-2-19-6-0.apk
python3 scripts/import-preservation.py /작업경로/recovered
python3 scripts/prepare-data.py
python3 scripts/prepare-tutorial-data.py
npm test
npm run check
```

큰 보존 ZIP과 원본 APK 자체는 저장소에 올리지 않았습니다. 전체 파일 인덱스·다운로드 위치·검증 해시·적용된 게임 자산과 스크립트는 저장소에 남겼습니다.
