# 원본 앱과의 차이·미구현·검증 체크리스트

작성일: 2026-10-25 (한국 시간). 최초 검토: 웹판 0.3.0 (`b21da298`). 이번 갱신: 웹판 0.4.0, 첫 작업인 기본 튜토리얼 연결. 수정 커밋은 이 문서와 `tutorial-journey-restoration.md`를 함께 갱신한 Git 이력으로 식별한다.

현재 실행 코드, APK 분석 기록, 공개 보존 파일 목록과 원문을 대조한 작업 목록이다. 이번 검토에서 원본 앱을 동시에 실행해 모든 화면을 픽셀 비교한 것은 아니다. 아래의 **검증 필요**는 차이가 확정됐다는 뜻이 아니다. 이 목록의 항목 수나 자산 확보 비율을 게임 전체 완성률로 계산하지 않는다.

- **차이 확인**: 현재 코드에 웹판용 대체 규칙·화면·연출이 확인됨.
- **미구현**: 해당 기능 또는 원본 자료를 실행하는 연결이 없음.
- **검증 필요**: 일부 구현·자료는 있으나 동일 버전·화면·프레임 일치 여부를 확인하지 못함.
- **P0**: 튜토리얼부터 원본처럼 이어지는 플레이를 만드는 선행 작업. **P1**: 화면과 규칙의 복원. **P2**: 전체 콘텐츠·온라인 확장.

한국어 화면과 원본 영어 BRAVE FRONTIER 로고는 사용자 요청대로 유지한다. 한국어로 바꾼 것 자체는 결함으로 분류하지 않는다. 정식 한국어판의 번역과 일치하는지는 별도 검증 대상이다.

## 1. 자료와 비교 기준

- [ ] **A01 · P0 · 검증 필요 — 버전·지역판 기준 통일.** 현재 APK 2.19.6.0, 2022년 글로벌 Windows 보존 자료, 2016년 한국어 유닛 자료, 2014년 글로벌 튜토리얼 전투 기록이 섞여 있다. 완료 기준: 각 화면·수치·규칙의 기준 버전과 출처를 고정하고 다른 버전에서 가져온 항목을 표시한다.
- [ ] **A02 · P1 · 검증 필요 — 남은 리소스 참조 92개 추적.** `BattleCritical.png`, `BattleSpark.png`, `Cutin.sam` 계열, 일부 배치 파일 등이 같은 파일 이름으로 확인되지 않았다. 완료 기준: 다른 이름·아틀라스에 들어 있는지까지 대조하고, 확보·대체·미확인 결과를 각각 기록한다. 92개 모두가 게임 실행에 반드시 필요한 독립 파일이라는 뜻은 아니다.
- [ ] **A03 · P0 · 미구현 — 확보한 자료를 실제 실행 구조에 연결.** 배치 CSV 715개와 튜토리얼 19개를 보존했지만 실행되는 화면·장면은 일부다. 완료 기준: 파일별 사용 화면·해석기·런타임 연결 여부를 추적할 수 있고, 복사만 된 파일을 구현 완료로 세지 않는다.
- [ ] **A04 · P1 · 검증 필요 — 전체 캐릭터 대상 목록 확정.** 보존 목록의 유닛 아틀라스 2,183개는 구현된 캐릭터 수나 완전한 원작 명단을 뜻하지 않는다. 완료 기준: 실제 유닛 ID, 진화 단계, 지역판·버전 중복, 필요한 이미지·모션·능력치·스킬을 대조한 명단을 만든다.

## 2. 공통 화면·홈·전환

- [ ] **B01 · P0 · 차이 확인 — 글꼴·글자 크기·줄바꿈·버튼 영역.** 원본 이미지 위에 시스템 한글 글꼴과 웹 라벨을 올리고 있다. 완료 기준: 기준 해상도에서 각 화면의 글자 기준선·여백·그림 가림·터치 영역을 원본과 대조해 맞춘다.
- [ ] **B02 · P1 · 검증 필요 — 화면 비율과 전체 배치.** 원본 640 기준 좌표와 반응형 CSS가 함께 쓰인다. 완료 기준: 원본 화면 비율과 세로로 긴 휴대폰에서 상단·본문·하단 메뉴가 의도한 위치에 있고, 원본을 늘이거나 잘라 생기는 차이를 기록한다.
- [ ] **B03 · P1 · 차이 확인 — 상단 랭크·경험치·기력.** 랭크는 완료 횟수 3회마다 상승하고 기력은 제한 없음으로 표시한다. 완료 기준: 원본 랭크 경험치·기력 소비·회복·상한 규칙과 표시를 연결한다.
- [ ] **B04 · P0 · 차이 확인 — 페이지 전환 전체.** 확인한 160ms 작업 레이어 이동은 편성과 유닛 상세 이동에만 적용했다. 나머지 화면은 즉시 전환하거나 웹 효과를 쓴다. 완료 기준: 화면별 나가기·들어오기·페이드·입력 차단·복귀 시점을 각각 원본 근거와 대조한다. 모든 전환을 일괄 320ms로 처리하지 않는다.
- [ ] **B05 · P1 · 차이 확인 — 팝업·선택·뒤로가기.** 공통 HTML 모달과 웹 버튼을 사용한다. 완료 기준: 원본 창 테두리·위치·열림/닫힘·확인/취소 순서·선택 상태를 화면별로 구현한다.
- [ ] **B06 · P1 · 차이 확인 — 홈 메뉴의 실제 역할.** 미션·저널·알림·상자 모양 버튼이 웹판 모험·편성·훈련·설정으로 연결된다. 뉴스·선물함·이벤트 등 원본 흐름은 없다. 완료 기준: 해당 버튼과 원본 목적 화면을 일치시키고 배너·표시 상태를 복원한다.
- [ ] **B07 · P1 · 검증 필요 — 타이틀·홈의 세부 움직임과 소리.** 원본 배경과 로고는 적용됐지만 입자·반짝임·배너 전환·버튼 반응·화면별 음악 시작과 종료의 전체 대응표가 없다. 완료 기준: 대표 동작을 원본 녹화와 비교하고 시점·반복 구간·음량 전환을 기록한다.
