# 튜토리얼 복원 기록

APK의 네 파일 전체를 `tutorial-source.json`에 보존하고, 도입 문자열을 `tutorial-strings-source.json`에 보존했습니다. 현재 실행되는 것은 `tuto1.txt`와 `tuto9.txt`를 대조한 한국어 훈련 두 장입니다. 각 대사·조작에는 원문 줄 번호가 연결되어 있습니다.

## 구현된 순서

| 원문 | 구간 | 대조한 내용 |
| --- | --- | --- |
| text.csv 304~308 | 루시어스 도입 | 다섯 대사, 이름 입력, 첫 영웅 선택으로 이동 |
| tuto1 113~163 | 첫 전투 | 적 체력, 행동 칸, 가운데→위→아래 공격, 다음 전투 |
| tuto1 170~264 | 두 번째 전투 | 뒤쪽 적 지정, 확인, 가운데→위→아래, 적 차례, 체력 0, 재공격, 하트 |
| tuto1 271~282 | 보물 상자 | 상자 표시, 직접 열기, 경고 |
| tuto1 290~327 | 보스 | 보스 등장과 선공, 아이템, 가운데 유닛 회복, 자유 전투 |
| tuto9 48~90 | 속성 | 물 적, 번개 유닛 공격, 상성 도표, 자유 전투 |
| tuto9 97~142 | 필살기 | 결정 무작위 배분, 게이지, 티리스 마법, 가운데 길게 누르기→오른쪽 위로 밀기→발동 |
| tuto9 149~152 | 보스 | 두 번째 장 보스, 자유 전투 |

첫 번째 퀘스트에는 필살기 훈련을 넣지 않았습니다. 필살기는 `tuto9`의 두 번째 전투입니다. 필수 조작이 끝나기 전 다른 유닛이나 다음 버튼으로 단계를 건너뛰지 못하도록 제한했습니다. 두 장 모두 전투 세 번, 완료 후 다시 보기와 현재 전투 처음부터 이어하기를 지원합니다.

## 화면·편성

`TutorialStepScene::initPartyStatus @0x1b938a4`에서 비리더 불 유닛=위(0), 비리더 번개=아래(1), 리더=가운데(2)를 확인했습니다. 0.5.0부터 현재 소유 부대의 불·번개 동료와 실제 레벨을 재사용합니다. 새 게임의 10030·40030 지급과 해당 속성이 없는 옛 저장의 임시 동료는 서버 초기 부대를 모르는 상황의 로컬 대체입니다. 전투 재연 자체는 저장을 바꾸지 않으며, 기본 경로 완료 보상은 별도로 한 번 기록합니다.

`setNaviWindow @0xfccd44`에서 확인한 창·초상화·텍스트 위치를 640 기준으로 적용했습니다. 안내 창 x0/y40, 640.2×180, 초상화 x12/y11, 168×200. 긴 한국어 문장을 위해 글자 크기·줄바꿈은 조정했습니다. 원본 Touch·Hold SAM, 원본 상자·하트·결정·초상화·소리를 사용합니다.

루시어스 도입의 `eff_page_1200_3.plist` 안 압축 이미지도 해석했습니다. 0.5.0에서 CSS 광원 대체를 제거하고 원본 수명·발생·색·크기·회전·가산 합성 및 도입 대사/전환 시간을 이식했습니다. 원본 난수열과 GPU 픽셀 동일성까지 검증한 것은 아닙니다.

## 2026-10-25 공개 자료 복구

19개 보존 튜토리얼 파일을 추가 확보했습니다. `tuto1`·`tuto9`는 APK에만 추적 이벤트(`id=10000`)가 추가되어 있고 대사·조작 내용은 일치합니다. `tuto15`·`tuto16`은 바이트까지 일치합니다. 추가 파일은 `preservation-tutorials.json`에 별도로 보존하여 APK의 원문 줄 번호를 유지합니다.

두 장의 적 구성·능력치를 2014 GL 캡처로 교체했습니다. 첫 장은 모릴스 / 라일스+모릴스 / 모릴스 킹(HP3000·ATK320·DEF30), 둘째 장은 미즐스+라일스+모릴스 / 모엘스+모릴스+라일스 / 스켈레톤(HP4000·ATK340·DEF20)입니다. 물 적 선택은 고정 배열 인덱스 대신 속성을 찾습니다. 캡처의 배열 순서를 유지하지만 원본 화면 슬롯 좌표는 아직 미확인입니다.

## 현재 연결과 남은 차이

- 0.4.0에서 APK 기본 경로 1→9→15→16→홈을 확인해 연결했습니다. 합성 안내 2~8은 기본 경로에서 건너뛰는 잔존 분기입니다. 필수 세 번째 퀘스트라는 이전 가정을 철회했습니다.
- 0.5.0에서는 원본과 근거가 다른 강제 피해·즉사·레벨2 승격을 제거했습니다. 일반 타격 예약과 튜토리얼 아군 HP1 보호를 사용합니다.
- 적 구성·수치는 2014 GL 캡처, 아군 마스터는 한국어 보존 자료이며 2022 동일성은 미확인입니다. 예외적으로 살아남은 적은 실제 전투 종료까지 추가 입력을 받아 진행합니다.
- 칼의 보석5 선물/소환과 별도로 APK 보상 이미지의 보석3·젤100,000은 기본 경로 완료 시 로컬에서 한 번 지급합니다. 원본 서버의 지급 처리와 전투 드롭·경험치는 미복원입니다.
- 한국어 문구는 직접 번역했습니다. 정식 한국어판 문구, 모든 스크립트 페이드, 효과 궤적·HP 카운터와 전체 전투 프레임은 미검증입니다.

자세한 근거와 재현 범위는 [0.5.0 작업 기록](tutorial-detail-restoration.md), 남은 일은 [체크리스트](original-parity-checklist.md)에 기록했습니다.
