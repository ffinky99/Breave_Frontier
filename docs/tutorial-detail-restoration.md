## 도입과 첫 영웅

`TutorialScene1::updateEvent @0x1b8ed90`의 분기는 대사1·2·3 → 이름 → 대사4 → 영웅 → 대사5 → 시작/건너뛰기 → 종료다. 종전의 카드 네 개와 대사 뒤 이름 입력을 이 순서로 교체했다.

| 항목 | 원본 근거 | 구현 |
| --- | --- | --- |
| 문자 출력 | AutoMessage baseSpeed15, speed10=6업데이트/문자; wait20=20업데이트 | 60Hz 논리 시계, 첫 터치 전체 표시, 다음 터치 진행 |
| 대사 영역 | (10,236,300,260), 글꼴15·간격8, 창/대기 화살표 숨김 | 같은 320 기준 영역에 한글 표시 |
| 이름 | 8자, 프레임(160,304), 버튼(48,372)/(176,372) | 조합 입력 지원·8자 제한·빈 이름 거부 |
| 영웅 | 순환 320×480 페이지, 그림 중심(160,240), alpha100/255 | 한 명씩 좌우 이동, 원본 그림·속성 설명 |
| 화살표 | ArrowLeft/Right SAM, 좌표(32,240)/(288,240) | 원본 24fps SAM·60Hz 이동, 감쇠0.92·13업데이트 안착 |
| 확정 | 버튼(109,320), 초기29업데이트 잠금, 직접 다음 대사 | 별도 영웅 확인/취소 창 없음 |
| 시작/건너뛰기 | TutorialSkipPopupScene, Start/Skip→Yes/No | 두 단계 확인·아니요 복귀·실제 건너뛰기 |
| 진입/종료 | 검정3초, 흰색3초→유지2초→검정1초 | 대기 중 입력 잠금; 원본 BGM 1초/3초 페이드 |

파티클은 `eff_page_1200_3.plist`의 내장 PNG를 사용한다. 40개 상한, 수명 `max(0, 0+5×[-1,1] 난수)`, 발생률 `40/0=Infinity`, 업데이트 시작에 빈칸 생성→수명 감소→죽은 입자 제거 순서를 따른다. 죽은 입자를 같은 업데이트에서 재생성하지 않는다. 위치(160,140), 속도/중력0, 선형 색/알파·크기·회전과 가산 합성을 적용했다. 초기 확대0.1→0.2/1초, 대사4 0.3/3초, 대사5 0.4/3초, 종료1/2초다.

한국어 글꼴과 문구, 무작위 이름 목록은 현지화다. 서버 이름 검사와 feature flag 조회는 복원하지 않았다. 화살표 프레임을 정적 분석과 대조했으며, 터치 이벤트마다 이동량을 ±17로 제한하고 1.2를 곱하는 속도와 해제 후 페이지 스냅도 이식했다. 실제 터치 장치 이벤트 빈도와 원본 RNG/GPU의 픽셀 결과는 동등성을 주장하지 않는다.

## 전투 시점과 실제 부대

유도 공격에서 임의로 적 최대HP의 1/3을 차감하거나 마지막 입력으로 죽이던 처리를 제거했다. 공용 `queueAction/advanceCombat`로 타격 프레임마다 HP를 차감한다. 원본 `BattleUnit::decHp @0x111dfbc`의 튜토리얼 아군 HP 최소1 보호와 `MissionScene::getTutoTarget @0x18193f4`의 첫 장 리더 타깃을 적용했다. 적을 강제로 처치하지 않는다.

`unit_stop_atk`는 첫 유닛과 위쪽 유닛을 누른 뒤 전투 업데이트 다섯 번만 수행한다. 여섯 번째 장면 검사에서 안내로 전환하고 타격·이동 시계를 정지한다. 다음 필수 유닛을 누르면 기존 공격과 새 공격이 함께 진행된다. 하단 유닛은 원문에 따라 전투 종료/적 차례 종료/현재 행동 종료까지 기다린다. 새로고침은 이전과 같이 현재 웨이브 처음부터 재개한다.

`tuto9`의 마법은 대사114를 넘긴 뒤 결정15개 생성 → 1.5초 → 수거 시작 → 1.5초 → 길게 누르기 순서다. 모두 위치2 리더에게 가며, 0~0.5초 무작위 지연 + 0.6초 이동(EaseIn1.2) 뒤 도착할 때 각각 게이지+1을 적용한다. 지원 유닛의 게이지를 최대치로 설정하지 않는다. 하트도 실제 도착 시 회복하고 부상 중인 생존자를 우선한다.

`PARAM100`의 세 번째 `none`은 이전 튜토리얼 이벤트를 유지한다. 따라서 하트 이벤트를 첫 공격 뒤 바로 지우지 않고 `clear`까지 유지하며, 스크립트 공격 이벤트별 첫 드롭을 보장한다. 일반 무작위 드롭 확률은 서버 자료가 없어 기존 로컬 값이다.

소유한 불/번개 동료를 원본의 위치0/1, 리더2로 재배치하며 기존 레벨을 유지한다. 새 게임 불/번개 지급과 해당 속성이 없는 옛 저장의 연습 동료는 로컬 대체이고, 원본 계정 초기 지급의 확정값이 아니다. 적 마스터는 여전히 2014 GL 캡처다. 이 조합에서 적이 남으면 실제 전투 종료까지 추가 입력을 받아 안내를 이어간다.

## 보상과 저장

APK `image_tutorial.png`에 적힌 보석3개와 젤100,000을 완료 보상으로 연결했다. 칼의 보석5 선물/소환 비용과 구분해 기본 안내 마지막 대사를 넘길 때 한 번 지급한다. 재화·완료 단계·`completionRewardClaimed`를 같은 저장에 기록한다. 건너뛰기와 임시 다시보기는 실제 저장에 완료 보상을 주지 않는다. 이전 완료 저장을 읽어 소급 지급하지 않는다. 이 모델은 APK에 표시된 보상의 로컬 구현이며 서버 지급 시점·전투 보상·경험치의 원본 동일성을 뜻하지 않는다.
