# 브레이브 프론티어 한국어 웹판

제공된 `brave-frontier-2-19-6-0.apk`의 이미지·캐릭터 모션·배경·음악을 이용해 만든 브라우저 게임입니다. 화면과 조작 안내는 한국어로 제공하며, BRAVE FRONTIER 로고는 원본을 유지합니다. 별도의 게임 서버, 로그인, 결제 없이 브라우저 안에서 진행합니다.

**원작 전체를 복원한 버전은 아닙니다.** APK에 들어 있는 그래픽은 실제 유닛 24종이며, 원본 리소스 목록의 파일 3,393개가 APK에 없습니다. 공개 보존 아카이브에서 이 중 3,301개를 추가 확보·검증했으며, 92개는 미확인입니다. 확보한 전체 자료가 아직 게임에 연결된 것은 아닙니다. 게임의 네이티브 실행 파일을 웹에서 그대로 실행한 것이 아니라, 확보한 자료를 읽어 화면과 게임 규칙을 자바스크립트로 다시 작성했습니다.

## 실행

Node.js 20 이상에서 별도의 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

터미널에 표시된 주소를 엽니다. 기본 주소는 `http://localhost:5173`입니다. `dist` 폴더를 정적 웹 호스팅에 올려도 동작합니다. 파일을 더블클릭하는 방식은 모듈·데이터 요청 제한 때문에 지원하지 않습니다.

```sh
npm test
npm run check
```

## Vercel 배포

Vercel에서 `ffinky99/Breave_Frontier` 저장소의 `main` 브랜치를 가져옵니다. 루트 디렉터리는 저장소 최상위로 둡니다. 저장소의 `vercel.json`이 프레임워크 없음, 별도 설치·빌드 없음, 출력 디렉터리 `dist`를 지정합니다. 환경 변수나 게임 서버 설정은 필요하지 않습니다.

배포 주소가 바뀌면 브라우저 저장 공간도 달라집니다. 기존 주소의 진행 상황을 옮기려면 게임 설정에서 저장 파일을 내보낸 뒤 새 주소에서 불러옵니다.

## 플레이할 수 있는 기능

- 루시어스 도입부와 이름 입력, 발가스·세레나·란셀·에젤 중 첫 영웅 선택
- 원문 `tuto1`·`tuto9`를 대조한 한국어 훈련 두 장: 목표 지정, 공격 순서, 하트·상자, 보스 선공, 회복약, 속성, 결정, 길게 누르기·필살기
- 두 훈련 뒤 칼의 보석 5개 선물·소환·작별·홈까지 연결, 장면별 이어하기와 기존 기록을 유지하는 다시보기
- 원본 캐릭터 24종의 전신 그림·유닛별 홈 crop과 대기·이동·공격 프레임 재생
- APK의 원본 배치 자료와 UI 이미지에 맞춘 모바일 화면: 상단 정보창, 다섯 캐릭터 칸, 여섯 메뉴, 전투 패널
- 로고를 제외한 원본 이미지의 영문은 한글 표기로 대체
- 유닛 상세의 원본 상태창 좌표와 소환 게이트·명령·손 안내 SAM 14종 재생
- 다섯 명까지 부대 편성, 속성 상성, 영웅 리더 스킬
- 공격·방어·필살기·일제 공격·자동 전투·두 배속·회복약
- 웹판에서 구성한 일반 모험 6개와 특별 모험 2개, 각각 연속 전투 3회
- 전투 보상, 성장, 일반 소환, 영웅 소환, 전체 도감
- 원본 배경 음악과 효과음, 소리 크기 설정
- 브라우저 자동 저장, 저장 파일 내보내기·불러오기

동료 칸을 누르면 현재 선택한 행동을 합니다. 길게 누르고 오른쪽 위로 밀면 필살기, 아래로 밀면 방어입니다. 키보드의 숫자 키 1~6도 사용할 수 있습니다. 모든 동료가 행동하면 적의 차례가 됩니다.

진행 상황은 현재 브라우저에 저장됩니다. 다른 기기나 주소로 옮길 때는 설정에서 저장 파일을 내려받아 불러오세요. 일반 전투 도중 새로고침하면 진행 중인 도전은 취소되며, 훈련은 현재 전투의 시작부터 이어집니다.  이미 획득한 재화와 동료는 유지됩니다. 처음 페이지와 자산을 불러올 때는 연결이 필요합니다. 오프라인 설치·캐시 기능은 포함하지 않습니다.

## 원본과 웹판의 구분

| 항목 | 사용한 자료와 구현 범위 |
| --- | --- |
| 캐릭터·배경·사운드 | 제공된 APK에서 추출, APK 220개·보존 일러스트 16개, 총 236개 파일의 해시 검증 |
| 캐릭터 프레임 | APK CGG·CGS 합성, 네이티브 60fps 확인, 24종 원문 타격 프레임·분배 검증 |
| 화면 연출 | SAM 14종의 24fps, 프레임별 변환·색상·투명도·구간 재생 |
| 일반 공격 | 네이티브 기본 피해·속성·치명타·방어·동일 프레임 스파크·결정 수신 규칙 대조 |
| 튜토리얼 | 대상 APK 기본 순서: 두 훈련 → 칼의 5보석 선물·소환 안내 → 작별 → 홈. 전투 수치는 2014 GL 캡처, 서버 지급 시점·전체 프레임 동일성은 미확인 |
| 한국어 이름·능력치·스킬 | 공개 한국어판 추출 자료 24종으로 보완 |
| 모험·적 배치·성장·소환 확률 | 웹판 규칙. 필살기의 전체 원작 효과 처리기는 미구현 |
| 원작 전체 이야기·진화·아레나·레이드·길드 | 미구현 |
| 원작 계정·서버·결제·다운로드 콘텐츠 | 포함하지 않음 |

한국어 추출 자료는 2016년 자료이므로, 제공된 글로벌 APK 버전과 모든 수치가 동일하다고 보장하지 않습니다. 앱 안에서도 이 차이를 설명합니다.

공개 자료의 확보 범위·버전 차이·재다운로드 방법은 [보존 자료 복구 기록](docs/보존-자료-복구.md)에 있습니다.

상세한 분석과 규칙은 [분석 기록](docs/분석-기록.md), [전투·프레임 대조](docs/전투-원본-대조.md), [튜토리얼 복원](docs/튜토리얼-복원.md), [캐릭터·페이지 검토표](docs/캐릭터-페이지-검토.md)에 있습니다. [검증 기록](docs/검증-기록.md)에는 자동 검증 41개와 실제 화면 확인 범위를 적었습니다.

## 파일 구성

- `dist/`: 정적 배포 파일, 게임 소스와 자산
- `dist/engine.js`: 전투·보상·성장·저장 검증 규칙
- `dist/tutorial-journey.js`: APK 기본 튜토리얼 연결과 원문 대사 위치
- `dist/sprites.js`: 원본 모션 합성기
- `dist/ui.js`, `dist/native.css`: 원본 UI 아틀라스와 모바일 화면 구성
- `scripts/extract-apk.py`: APK 재추출 및 해시 기록
- `scripts/prepare-data.py`: 한국어 유닛 데이터 변환
- `docs/apk-inventory.json`: 원본 목록, 누락 자료, 복사 자산 해시
- `docs/units-source-kr.json`: 참조한 한국어 유닛 자료 원문
- `tests/engine.test.js`: 주요 게임 흐름 검증

원본 APK 자체와 네이티브 실행 파일은 저장소에 포함하지 않습니다. 같은 APK를 가지고 있다면 다음 명령으로 자산·모션과 한국어 데이터를 재생성할 수 있습니다.

```sh
python3 scripts/extract-apk.py /경로/brave-frontier-2-19-6-0.apk
python3 scripts/recover-preservation.py /작업경로/recovered
python3 scripts/import-preservation.py /작업경로/recovered
python3 scripts/prepare-data.py
python3 scripts/prepare-tutorial-data.py
npm run check
```
